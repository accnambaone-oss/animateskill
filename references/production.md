# Local production

Use Python 3.10+ in a project environment, Node 22+, Chromium and FFmpeg/FFprobe on PATH (FFmpeg with libx264, AAC and subtitles/libass). Install the Kokoro voice dependency with pip install kokoro soundfile numpy. Install eSpeak NG for English fallback pronunciation. Download the chosen Kokoro model and voice once before offline work. For the optional browser capture driver install playwright and run python -m playwright install chromium or specify an installed Chrome with --chromium.

Install the HyperFrames CLI locally in the production workspace with npm install --save-exact hyperframes gsap and check npx hyperframes doctor. Keep the lockfile. Initialize production shot folders using the installed CLI's init command. Copy bundled GSAP locally into each composition that uses it and reference it as gsap.min.js before the scene script. Set a paused timeline in window.__timelines under the composition ID. Author deterministic seekable animation. Put the composition and all visual assets under its shot directory. Use the installed CLI's render --help to check PNG sequence support.

Study the upstream Claude Animated Shorts skill and templates at https://github.com/mromidev/claude-animated-shorts . For physical action adapt its camera-key approach, separately posed character cards, foreground occlusion, contact cues and workprint inspection. For Three.js derive world transforms, camera and pose from the passed time. Call renderer.render(scene,camera) after posing; avoid frame-to-frame integration and wall-clock animation. Build original art. Upstream reference frames are for study. Its original duration, resolution and voice settings belong to its bridge example. Our project uses the user's timing and local Kokoro. HyperFrames source: https://github.com/heygen-com/hyperframes . Kokoro: https://github.com/hexgrad/kokoro .

## Project contract

Make project.json using assets/demo.json as a starting point. Paths are relative to the manifest. Shots play in list order. Each shot contains its own index.html, data-width, data-height, data-duration (frames / 24), data-fps=24 and independent timeline. The example exposes drawFrame(frame) for the explicit browser driver and registers a paused GSAP clock when local GSAP is present. Copy gsap.min.js beside index.html before rendering the example with HyperFrames. The browser driver calls drawFrame itself. Implement this hook for every scene rendered through that driver.

Use scripts/voice.py speech.json voice to generate a timing manifest and WAVs. speech.json is an array of objects with text, optionally voice, speed and pause_after. Silence after each phrase is expressed in seconds. The output passages.json contains global start frames from zero, relative WAV paths and texts. Copy its entries into project.json speech, adjusting paths relative to project.json. For pauses or action inserted between lines adjust frame offsets. The final shot sequence must cover every recorded line. Split long narration into readable caption phrases before synthesis.

Run python scripts/film.py PROJECT/project.json --engine hyperframes --hyperframes /absolute/path/to/hyperframes to render and produce draft.mp4, motion.mp4 (caption-free, silent), mix.wav, speech.wav, effects.wav, subtitles.srt and verification.json in the project's build folder. On Windows use the installed hyperframes.cmd launcher. Browser alternative for drawFrame scenes: --engine browser. Add --chromium PATH for system Chromium. Outputs with the same build path should be rendered by one process at a time. Valid cached shots are reused on restart. The browser driver checkpoints each frame, HyperFrames checkpoints complete shots. For low-resource previews author a scaled project copy or use the verified motion.mp4; maintain the 24 fps time base.

After playback review of the current draft, save review.md with one observed cause and consequence for every action shot, corrections and sound/caption/credit checks. Include the current draft SHA-256 from verification.json in review.md to bind observations to that exact export. Run the same film command with --approve-reviewed. This produces final.mp4 from the reviewed draft, records the draft hash and requires a current review. For technical-only testing keep draft status. Save software versions and package locks alongside the project.

The demo has one fictional six-second shot and no spoken passages. It tests picture and Foley only. Create the user's actual topic as a separate project with research, Kokoro speech and source credit shots. To try the demo, copy assets/ into an empty working directory and point film.py at its demo.json. The output directory is next to that manifest.

For inline SVG scenes that only set element attributes inside drawFrame, the optional --engine svg renders those same poses with Node and sharp. Install sharp where Node can resolve it from scripts/svg_frames.cjs, or set NODE_PATH to the directory containing sharp. This driver supports self-contained SVG using double-quoted attributes and inline JS, with no CSS layout, external assets or Three.js. Use the HyperFrames engine for the full composition. All scene code is trusted project code. The Python render drivers require numpy and Pillow.
