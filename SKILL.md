# Render local animation

Accept a topic as the only required input. Work in a new project directory. Carry research, writing, scene authoring, audio, preview, revision and delivery through automatically. Default to English, 720×1280 and 24 fps. Choose duration freely from the material. Honor explicit overrides for format, audience, tone and length. Use web access for research and dependency setup. Render and synthesize locally.

## Research and direct

1. Write the central question and research its premise using primary documents or reliable subject specialists. Record author, title, date, URL, relevant passage and uncertainty in sources.md. Connect each factual line, graphic and number to its source. Identify allegories and reconstructions. If evidence changes the premise, change the story.
2. Write script.md with paired narration and visible events. Open on something the viewer can see happen. Use discoveries and consequences to build toward a closing payoff. Include benefits or harmful uses when supported and relevant. Select the shortest natural telling. No fixed runtime range.
3. Follow references/production.md to install the local tools, synthesize Kokoro passages and obtain their measured lengths. Make project.json with one or more shots and global speech and Foley cues. Schedule action and narration concurrently. Include silence for reveals and readable credit frames.
4. Author each shot as its own local HyperFrames composition. The example in assets/rope-lift demonstrates direct-frame posing, independent limbs, rope tension, camera-stable reference points and a three-stage payoff. Create original topic-specific scenes. Adapt Claude Animated Shorts staging or Three.js world techniques as described in the production guide. Use an articulated subject, an interacting object or a visibly changing mechanism for each action beat.
5. Record each shot's purpose, establishing pose, contact or change, consequence, lens/framing, focal subject, continuity and cue frames. Build the parts the action requires before finalizing artwork. Place captions via the export script. Author source credits in the picture and retain full references separately.
6. Render draft footage with the bundled driver. Watch each action shot at normal speed, captions hidden and muted. Record what changed, why and what persisted in review.md. Pixel differences and keyframe sheets alone cannot verify motion. When an event is unclear, revise staging, timing or articulated parts and rerender. Use a deliberate hold for evidence or reaction when its duration serves the story.
7. Review audio, caption alignment, legibility, edit rhythm, source credits and continuity on the captioned draft. Check individual source facts against the final spoken and visible text. Run the final export only after playback review. If playback inspection or a required dependency is unavailable, identify precisely what remains unverified. Never substitute a different voice and call it Kokoro.
8. Deliver final.mp4, subtitles.srt, script, sources, audio stems, editable compositions and frame cache. Report actual runtime, dimensions and decoded frame count. Keep render artifacts outside the skill folder.
